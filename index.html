01·Basics/variables & types

A variable is a name for a value

Write name = value and Python remembers it. Every value has a type, and the type decides what you can do with it.

input() always returns text, so "5" + "5" gives "55". Convert first: int("5") + 5 is 10.

age = 20               # int

Lowercase words joined by _: total_price.

Case-sensitive

Age and age are two different variables.

No digit first

A variable is a label stuck on a value. Python works out the type for you; type() tells you what it decided. Conversions like int() and float() are how you turn user input or text from a file into numbers you can calculate with.
01·Basics/operators

Python is a calculator that follows maths rules

OperatorMeaningExampleResult

round(2.5) is 2 and round(3.5) is 4: Python rounds halves to the nearest even number.

a = 10

Most operators are what you expect. The three to remember are slash, double slash and percent: real division, whole division and remainder. Precedence follows school maths, and brackets always win.
01·Basics/functions

Functions: write it once, use it everywhere

A function packs steps under a name. Define it once with def, give it inputs (parameters), and it hands back a result with return.

Why it matters for AI & data
  • print(), len() and pd.read_csv() are functions someone else wrote. Writing your own is how you stop copy-pasting code.
Anatomy
def→starts a function definition (x)→parameter: the input """…"""→docstring: what it does return→the result sent back
GOTCHA
print only shows a value; return gives it back. A function without return returns None.
01_basics.py
def double(x):
    """Return the double of x."""
    return 2 * x

def greet(name, greeting="Hello"):
    return f"{greeting}, {name}!"

print(double(3))           # 6
print(greet("Ana"))        # Hello, Ana!
print(greet("Rui", "Hi"))  # Hi, Rui!
The indented block under def is the body. Parameters can have default values, like greeting here. The docstring is what you see when you type double? in a notebook. Stress the difference between print and return: it is the most common beginner bug.
01·Basics/strings

Strings: text you can slice, search and format

A string is a sequence of characters. Index it, slice it with [start:stop], transform it with methods and build it with f-strings.

index012345 wordPython negative-6-5-4-3-2-1
Why it matters for AI & data
  • Prompts, documents, reviews and LLM answers are all strings. Cleaning text is step one of every language project.
GOTCHA
Strings are immutable: word[0] = "J" raises TypeError. Methods like .upper() return a new string.
01_basics.py
word = "Python"
print(word[0])       # P
print(word[-1])      # n
print(word[0:3])     # Pyt  (stop is excluded)
print(word[::-1])    # nohtyP

print(word.upper())        # PYTHON
print("th" in word)        # True
print(len(word))           # 6
print("a,b,c".split(","))  # ['a', 'b', 'c']

name, score = "Ana", 0.875
print(f"{name} scored {score:.1%}")
# Ana scored 87.5%
Strings use the same zero-based indexing we will see for lists. Negative indices count from the end. f-strings, with an f before the quotes, are the modern way to put values inside text, and the part after the colon controls the format.
01·Basics/conditions

if / elif / else: let the program decide

Python tests each condition in order and runs the first block that is True. else catches everything left over.

CompareCombine
== !=and both must be True
< > <= >=or at least one is True
0 <= x <= 10not flips True and False
GOTCHA
= assigns, == compares. And indentation is the syntax: the 4 spaces decide which lines belong to the if.
01_basics.py
age = 20

if age < 18:
    print("Minor")
elif age < 65:
    print("Adult")
else:
    print("Senior")
# Adult

x = 5
print(0 <= x <= 10)          # True
print(x > 0 and x % 2 == 0)  # False
Why it matters for AI & data
  • Every rule in a program is an if: flag a transaction, pick a label from a model's score, skip an empty row.
Walk the age example: 20 is not under 18, so Python moves to elif; 20 is under 65, so it prints Adult and skips the rest. Comparisons give True or False, and and/or/not combine them. Python even lets you chain comparisons like in maths.

02·Data structures/overview

Your container choice decides your operations

A data structure is a way to organize, store and access data efficiently. It decides how you can access, search, modify and iterate over a collection.

StructureSyntaxOrderedMutableDuplicatesReach for it when…
list["a", "b"]YesYesYesorder matters and items change often
tuple("a", "b")YesNoYesdata is constant and must not change
set{"a", "b"}NoYesNoyou need unique items or group comparisons
dict{"k": "v"}Yes*Yeskeys: Noyou look values up by a name, ID or category

Why it matters for AI & data
  • Model inputs and outputs travel in these four shapes. An LLM's JSON reply is a dict of lists.
GOTCHA
Checking x in my_set is near-instant; x in my_list scans every item. On millions of rows, the wrong container is the slow pipeline.
One table to remember: ordered, mutable, duplicates. The rest of this module zooms into each row with a concrete example.
02·Data structures/core concepts

Python counts from zero. Plan for it

Every ordered collection is zero-indexed: the first element sits at position 0, the last at len - 1.

Why it matters for AI & data
  • Row 0 of a DataFrame, token 0 of a sentence, the first prediction in a batch: zero-indexing is everywhere in AI tooling.
  • Off-by-one errors silently shift data: the wrong row gets the wrong label.
GOTCHA
This list has 6 items, so the last index is 5. my_list[6] raises IndexError; my_list[-1] returns the last item.
index012345 my_list29"Rafael"-9"courses"[1,2,3,4,5]"Test"
6 items → indices 0 … 5 · int, str and list in one collection

Iterable

You can loop over it, one item at a time: the engine of Module 03.

Mutable vs immutable

Can it change after creation? Lists can; tuples can't.

Mixed types

One collection can hold numbers, text and even other lists. Exception: set items and dict keys must be immutable.

Python starts counting at zero. It sounds trivial; it is the source of countless off-by-one bugs that quietly misalign data and labels.
02·Data structures/list

Lists: the default home for ordered, changing data

A list is an ordered, mutable collection that allows duplicates: the most-used structure for sequences of data.

Why it matters for AI & data
  • A queue of documents to process, a batch of predictions: anything ordered that grows and shrinks.
  • Lists are the raw material Pandas turns into columns (Module 05).
GOTCHA
remove() deletes only the first match, and raises ValueError if the item isn't there. Check with in first.
01_data_structures.py
fruits = ["apple", "banana", "orange"]
print(fruits[1])  # banana

fruits.append("watermelon")
print(fruits)  # ["apple", "banana", "orange", "watermelon"]

fruits.remove("banana")
print(fruits)  # ["apple", "orange", "watermelon"]
When to use it
  • When you need to change, add or remove items frequently.
  • When order matters.
Lists are the workhorse. Index 1 is the second item, append adds to the end, remove deletes the first match.
02·Data structures/tuple

Tuples: lock data you never want changed

A tuple is an ordered, immutable collection: once created it can't be modified, which makes it efficient in memory and safe for data.

Why it matters for AI & data
  • Fixed records: coordinates, an image's (height, width), a (date, value) pair.
  • Immutability is a safety net: reference data can't be changed by accident mid-pipeline.
GOTCHA
A one-item tuple needs a trailing comma: (10,) is a tuple, (10) is just the number 10.
01_data_structures.py
coordinates = (10, 20)
print(coordinates[0])  # 10

data = ("John", 25, "Lisbon")
name, age, city = data
print(name)  # John
print(city)  # Lisbon
When to use it
  • When data is constant and must not be changed.
  • As dictionary keys, or to return multiple values from a function.
Tuples are lists with a lock. Line 5 shows unpacking: three variables filled from one tuple in a single line, a pattern you will see everywhere in AI code.
02·Data structures/set

Sets: kill duplicates, compare groups instantly

A set is an unordered collection with no duplicates, built for math-style operations: union, intersection, difference.

Why it matters for AI & data
  • Deduplicate customer IDs or labels in one step.
  • Compare cohorts: used A and B (&), A or B (|), A but not B (-).
GOTCHA
Sets have no order, so printed order can vary between runs. And {} creates an empty dict; use set() for an empty set.
01_data_structures.py
colors = {"red", "blue", "green"}

colors.add("yellow")
colors.remove("blue")
print(colors)  # {'red', 'green', 'yellow'}

## --- ##

A = {1, 2, 3}
B = {3, 4, 5}

print(A | B)  # Union: {1, 2, 3, 4, 5}
print(A & B)  # Intersection: {3}
print(A - B)  # Difference: {1, 2}
Sets answer "who is in both groups?" in one character. That is a question data analysts ask every day: who bought A and B, who left, who is new.
02·Data structures/dict

Dictionaries: key → value, the shape of every API

A dictionary stores key:value pairs. Keys are unique and immutable (string, number, tuple), so you can jump straight to a value by its name.

Why it matters for AI & data
  • JSON from APIs and LLM responses loads straight into dicts.
  • Map IDs to records, categories to labels, settings to values.
GOTCHA
student["email"] raises KeyError when the key is missing. student.get("email") returns None instead of crashing.
01_data_structures.py
student = {"name": "Ana", "age": 22, "course": "Data Science"}
print(student["name"])   # Ana
student["age"] = 23      # Update value
student["grade"] = 18    # Add new key
Anatomy
"name"→"Ana" "age"→22 → 23updated "course"→"Data Science" "grade"→18new
If you have ever looked at a JSON response from an API or an LLM, you have read a dictionary. Keys on the left, values on the right.

What is a loop?

The journey
You can store data. Now make it work at scale.

Writing an instruction three times is fine. Three million times is not. Loops make one instruction run over every item in a list, tuple, set or dict.

▶ notebooks/03_Loops  ·  📚 W3Schools
Module three. We have containers full of data; now we need to do something to every item without copy-pasting code.
03·Loops/why loops

Loops turn one instruction into a thousand

A loop repeats a set of instructions automatically. Instead of writing the same code many times, the loop does it for you.

Why it matters for AI & data
  • Cleaner, shorter, easier to maintain: change the logic once, not in every copy.
  • Every batch job (scoring records, evaluating a model on each test case, calling an API per row) is a loop.
TAKEAWAY
All three versions print the same three lines. Only the loops still work when 3 becomes 3,000,000.
02_loops.py
# Without a loop:
print("I'm going to study Python!")
print("I'm going to study Python!")
print("I'm going to study Python!")

# With a while loop:
i = 0
while i < 3:
    print("I'm going to study Python!")
    i += 1

# With a for loop:
for i in range(3):
    print("I'm going to study Python!")
Same output, three ways. The first version doesn't scale. The while and for versions do, and they are what we unpack next.
03·Loops/while: conditional loop

while: repeat until the condition says stop

while repeats a block as long as a condition is True. It asks a yes/no question before every pass and stops at the first "no".

Why it matters for AI & data
  • Use it when you don't know the count up front: poll until a job finishes, retry until an API answers, train until accuracy stops improving.
GOTCHA
Forget counter += 1 and the condition never turns False: an infinite loop. Always move something toward the exit.
02_loops.py
counter = 1
while counter <= 3:
    print("Hello!")
    counter += 1
  1. counter starts at 1.
  2. while asks: "is counter ≤ 3?"
  3. If yes, print "Hello!" and add 1 to counter.
  4. When counter reaches 4, the condition is False and the loop ends.
Walk the flowchart with the steps. The loop-back arrow is the whole idea: check, act, update, check again.
03·Loops/for: sequential loop

for: walk any sequence, one item at a time

for is ideal when you know up front how many times to repeat, or want to visit every item of a sequence: a range of numbers, a string, a list.

Numbers · range()
for i in range(3):
    print("Hello!", i)

Why it matters for AI & data
  • Apply the same step to every record: clean each text, score each customer. Pandas (next) runs this loop for you.

Three sequences, one pattern. Notice the middle example: a string is a sequence of characters. That idea comes back when we count words in Module 06.
03·Loops/break, continue & comprehensions

Steer the loop, then write it in one line

break leaves the loop early; continue skips to the next item.

03_loops.py
numbers = [4, 7, -1, 10, 3]

for n in numbers:
    if n < 0:
        print("Negative found, stop")
        break
    if n % 2 == 1:
        continue        # skip odd numbers
    print(n)
# 4
# Negative found, stop
GOTCHA
while True: runs forever unless something inside reaches a break. Make sure one always will.

A list comprehension builds a new list from a loop, in one readable line.

03_loops.py
# The classic loop
squares = []
for n in range(5):
    squares.append(n ** 2)

# The same, as a comprehension
squares = [n ** 2 for n in range(5)]
print(squares)   # [0, 1, 4, 9, 16]

# With a filter
evens = [n for n in range(10) if n % 2 == 0]
print(evens)     # [0, 2, 4, 6, 8]
TAKEAWAY
Read it as "n squared, for each n in the range, if…". If it no longer fits in one clear line, go back to a normal loop.
Trace the left example with the class: 4 is even, so it prints; 7 is odd, so continue skips it; -1 is negative, so break ends the loop and 10 and 3 are never visited. On the right, the comprehension does exactly what the four-line loop does. You will see comprehensions everywhere in data code.

04·Reuse/modules & imports

import: build on code that already works

A module is a .py file full of functions. import brings it into your program, so you don't rewrite what already exists.

Why it matters for AI & data
  • Every AI notebook starts with imports: import pandas as pd. The library ecosystem is the reason Python leads in AI.
GOTCHA
Never name your own file pandas.py or random.py: Python imports your file instead of the library. And avoid from x import *.
04_reuse.py
import math
from random import choice
from collections import Counter
import pandas as pd       # alias by convention

print(math.sqrt(16))            # 4.0
print(choice(["red", "blue"]))  # a random pick

words = "to be or not to be".split()
print(Counter(words).most_common(2))
# [('to', 2), ('be', 2)]

Standard library

Comes with Python: math, random, json, datetime.

Third party

Install once with uv add pandas, then import.

Your own

Save utils.py next to your code: import utils.

Three places code comes from: the standard library that ships with Python, third-party libraries you add with uv, and your own files. The as keyword gives a short alias; pd, np, plt and sns are conventions the whole community uses.
04·Reuse/errors & exceptions

Errors are messages: read them, then handle them

When something goes wrong, Python raises an exception and prints a traceback. Read the last line first: it names the error and the reason.

traceback
Traceback (most recent call last):
  File "app.py", line 2, in <module>
    age = int("twenty")
ValueError: invalid literal for int() with base 10: 'twenty'
NameErrorTypeErrorValueErrorKeyErrorIndexErrorZeroDivisionErrorFileNotFoundError
GOTCHA
Never write a bare except:. It hides real bugs too. Catch the specific error you expect.
04_reuse.py
def to_number(text):
    try:
        return int(text)
    except ValueError:
        print(f"'{text}' is not a number")
        return None

print(to_number("42"))      # 42
print(to_number("twenty"))  # 'twenty' is not a number
                            # None
Why it matters for AI & data
  • Files go missing, APIs time out, people type "abc" where a number belongs. try/except keeps the program running and tells you what failed.
Errors are not failures, they are information. Teach the habit of reading the last line of the traceback first. Then show try/except: the risky line goes in try, the plan B in except. Only catch the errors you expect.
04·Reuse/classes & objects

Classes bundle data and behaviour into objects

A class is a blueprint; an object is one thing built from it. Attributes hold its data and methods are the functions it can run.

Why it matters for AI & data
  • You already use objects: fruits.append(), df.head(). AI models are too: model.fit(X, y).
Anatomy
class→the blueprint: BankAccount __init__→runs when an object is created self.balance→an attribute (the object's data) deposit()→a method
GOTCHA
Every method takes self as its first parameter: it is the object itself. Forget it and you get a TypeError about arguments.
04_reuse.py
class BankAccount:
    def __init__(self, owner, balance=0):
        self.owner = owner
        self.balance = balance

    def deposit(self, amount):
        if amount <= 0:
            raise ValueError("Amount must be positive")
        self.balance += amount

account = BankAccount("Ana")
account.deposit(50)
print(account.owner, account.balance)  # Ana 50
One blueprint, many objects: two accounts share the same methods but keep their own balance. Notice that deposit raises a ValueError for invalid amounts, so classes and exceptions work together. When you call df.head() in the next module, you are calling a method on a DataFrame object.

05·Pandas/Series & DataFrame

Series is a column; DataFrame is the table

A Series is one-dimensional: values with labels (the index). A DataFrame is two-dimensional: rows and columns, like an Excel sheet. Think of it as a dictionary of columns (Module 02).

Why it matters for AI & data
  • The DataFrame is the input format ML libraries such as scikit-learn expect.

A document that mixes text and code you can run piece by piece.

Library
Code other people wrote that you can import and reuse.
Loop
Repeats the same steps for every item, or until a condition stops it.
Error
Python's message that something went wrong, and where.

A blueprint, and the things built from it.

A table of rows and columns inside Python, like a spreadsheet.
